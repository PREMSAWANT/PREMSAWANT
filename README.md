### 💼 Technical Profile

I am a backend-focused engineer specializing in the **Java and Spring Boot** ecosystem. I focus on building robust enterprise architectures with strict separation of concerns, defensive validation, and high maintainability.

- 🏗️ **Architectural Discipline**: Layered architecture (`Controller` → `Service` → `DAO` → `Repository` → `Entity`) with zero entity leakage via explicit DTO mapping.
- ⚙️ **Core Backend**: Strong expertise in **Java 17**, **Spring Boot**, **Spring Data JPA**, and **Hibernate ORM**.
- 🗄️ **Data Integrity**: Relational modeling (`OneToMany`, `ManyToMany`, `OneToOne`), constraint validation, and transactional consistency with **PostgreSQL** and **MySQL**.
- 🛡️ **Defensive Engineering**: Centralized exception handling via `@RestControllerAdvice`, OTP lifecycles with SMTP email dispatch, and Swagger/OpenAPI documentation.
